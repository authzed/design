Install

pnpm add @authzed/fonts
@import '@authzed/fonts/display.css';

h1 {
  font-family: var(--font-headline);
  font-weight: 300;        /* sets up */
  font-stretch: 100%;      /* 58.5% to 165% */
}
h1 strong { font-weight: 600; } /* lands */

Rules

  • 32px and up. Body, nav, buttons, labels and captions stay Inter; code stays JetBrains Mono.
  • 300 sets up, 600 lands, at the same size, with the 600 clause on its own line.
  • Normal by default. Step down to Condensed before stepping down in size. Compressed is for all-caps heroes. Wide and Expanded are for a word or two.
  • No tracking by default. −0.025em is the ceiling, on 300 only.
  • Gradient on the 600 clause only.
